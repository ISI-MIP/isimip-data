The files are masked using the command: cdo -f nc4c -z zip_5 -ifthen IFILE -selname,mask LANDSEAMASK OFILE.

Everything outside is set to missing_value and the grid is kept.

We are using the ISIMIP3 land-sea mask, which is the land-sea mask of the W5E5 dataset.

By default, we are using the version without Antarctica. The version including Antarctica can be selected below.
