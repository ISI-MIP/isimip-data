The files are masked using the command: cdo -f nc4c -z zip_5 -ifthen IFILE -selname,m_COUNTRY COUNTRYMASK OFILE.

Everything outside is set to missing_value and the grid is kept.

By default, we are using the ISIMIP3 countrymask, which was also used for the ISIMIP3 population and GDP data. Before Aug 3, 2026, we used the older ISIpedia country masks (v2.6). The new mask differs in ~500 pixels, making 110 of the countries slightly smaller. This can lead to different, more accurate results, in particular with smaller countries. If you still need to access the old mask, you can select it below.

Important: Our binary country masks are constructed in such a way that any grid cell touched by the country is fully counted for that country. One effect of this is that grid cells may belong to more than one country. Also, the calculation of the field mean for the country will be different than when using a fractional mask.
